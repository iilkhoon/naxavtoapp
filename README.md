## 📌 Layihə Haqqında

**NaxAvto**, Naxçıvan bölgəsindəki sürücülər, sərnişinlər və avtomobil sahibləri üçün nəqliyyat və servis xidmətlərini asanlaşdırmaq məqsədilə hazırlanmışdır. Müasir interfeys, sürətli arxitektura və rahat istifadəçi təcrübəsi ilə yerli ehtiyaclara uyğun həllər təqdim edir.

---

## ✨ Özəlliklər

- 🚘 **Avtomobil Elanları və İcarə:** Aktual elan bazası, rahat filtrləmə və icarə seçimləri.
- 📍 **Məkan Əsaslı Xidmətlər:** Xəritə inteqrasiyası ilə ən yaxın usta, servis və ya transfer nöqtələrini tapmaq imkanı.
- 📱 **Müasir İnterfeys:** Sadə, axıcı və intuitiv UI/UX dizaynı.
- 🔔 **Real Vaxt Bildirişləri:** Sifariş və status yeniləmələri üçün bildiriş sistemi.
- 🌓 **Tema Dəstəyi:** İşıqlı (Light) və Qaranlıq (Dark) rejim.

---

## 🛠️ Texnologiyalar

- **Freymvork:** React Native / Expo
- **Proqramlaşdırma Dili:** TypeScript / JavaScript
- **Vizual Tərtibat:** Tailwind CSS (NativeWind) / StyleSheet
- **Vəziyyət İdarəetməsi (State):** Context API / Redux Toolkit
- **Paket Meneceri:** npm
